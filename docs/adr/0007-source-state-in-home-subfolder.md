# Source State lives in `home/`, scripts grouped under `.chezmoiscripts/`

ADR-0002 made the repo root the Source Dir, which left `dot_*` files, `AppData/`/`Library/`/`Documents/`, seven `run_*` scripts, a migration helper and repo meta (README, docs, CI, agent files) side by side at the root — hard to scan, and every new meta file needed a `.chezmoiignore` entry so it wouldn't be deployed into `$HOME`. We're adding a `.chezmoiroot` containing `home`, so chezmoi reads its Source State from `home/` while the repo root keeps only repo meta, and moving every `run_*` script into `home/.chezmoiscripts/{unix,darwin,linux,windows}/`, which chezmoi runs without creating a directory in `$HOME`.

This refines ADR-0002 rather than reversing it: the repo is still the Source Dir and still uses chezmoi's naming convention (`dot_` stays — it's how chezmoi maps names, and dropping it would mean the translation layer ADR-0002 rejected). The script subfolders are for orientation only; each script keeps its own OS guard in its template, so a misplaced script can't run on the wrong Target. Moving the scripts renames their target paths, so `run_onchange_` scripts run once more on each machine after this change (all of them are idempotent package installs); `run_once_` scripts are keyed by content and don't rerun.
