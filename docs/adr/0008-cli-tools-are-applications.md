# CLI tools the configs rely on are Applications on every Profile

The deployed configs assume tools no script installed: git's `pager = delta`, `starship init` in `.bashrc` and the PowerShell profile, tmux's tpm plugins (and fzf for tmux-sessionx), Yazi with its glow/bat previewers and `package.toml` plugins. On a fresh machine that meant a broken `git diff`, an error on every bash/pwsh start, and an unthemed tmux. We're adding these CLI tools (delta, starship, neovim, tmux, fzf, zoxide, yazi, glow, bat, lazygit) to the Application list of every Profile, dev-server included — ADR-0006 already defined Application as covering CLI tools and GUI apps alike, so this fills the list rather than adding a category. They install through the same per-platform manifests (`brew` lines in the Brewfile, `apt-packages.txt`, the winget manifest), not through `mise`: mise stays for language runtimes, and its tool registry doesn't cover this set any better than the platform package managers do.

Two `run_onchange_after_` scripts take care of the plugin layers on top: `install-tmux-plugins` clones tpm into `~/.config/tmux/plugins` and runs its `install_plugins` (rerun keyed on `tmux.conf`'s hash), and `install-yazi-plugins` runs `ya pkg install` (rerun keyed on `package.toml`'s hash, with a Windows sibling). Both skip with a warning when the tool itself is missing, and both sort after the Application installs so the tool is normally there by then. psmux's plugins on Windows stay a manual step.

**Consequences:** the apt manifest now names packages that older Debian/Ubuntu releases don't ship (starship, yazi, glow, lazygit at least) — rather than drop them from Linux entirely, the Linux install script checks each package with `apt-cache show`, installs those that exist and prints the rest as a warning, so one missing name no longer fails the whole apply. `winget import` gets `--ignore-unavailable` for the same reason. Configs that call these tools still guard their calls (`command -v starship`, `Get-Command starship`), so a machine where an install was skipped stays usable. dev-server's Application list is no longer empty; its GUI configs stay excluded because `.chezmoiignore` keys them on the individual GUI app names.

**Update:** for Linux, ADR 0012 moves the CLI tools to mise; apt keeps system packages and GUI apps.
