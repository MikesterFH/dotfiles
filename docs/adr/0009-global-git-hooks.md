# Global git hooks strip coding-agent attribution

Coding agents (Claude Code, Codex, Copilot, …) append `Co-Authored-By:` and "Generated with" lines to commit messages by default, and each agent has its own switch, if any. We're setting `core.hooksPath = ~/.config/git/hooks` in the deployed git config, with a `commit-msg` hook that removes those lines whichever tool wrote the commit; `AGENTS.md` and Claude Code's `attribution` setting ask agents not to write them in the first place, the hook is the backstop. Only trailers naming an agent are removed, so a human `Co-authored-by:` survives.

**Consequences:** a global `core.hooksPath` makes git ignore every repo's `.git/hooks`. So every standard client hook in `~/.config/git/hooks` ends by calling `run-repo-hook`, which runs the repo's own hook of the same name if it exists — `pre-commit`-framework and similar installs keep working. A repo that sets its own `core.hooksPath` (husky, lefthook) takes precedence over the global one and gets no trailer filtering; accepted, since `AGENTS.md` still applies there. Hook types not wrapped here (e.g. `reference-transaction`) stop running from `.git/hooks`; none are in use today.
