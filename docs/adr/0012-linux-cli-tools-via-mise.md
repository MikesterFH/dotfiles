# 0012: Linux CLI tools via mise

**Context:** ADR 0008 installs the CLI tool Applications through each platform's package manager and keeps mise for language runtimes. On Debian/Ubuntu that leaves a Neovim unable to run this setup: Ubuntu 24.04 ships Neovim 0.9.5 and Debian 12 ships 0.7.2, while LazyVim needs 0.11 and nvim-treesitter's `main` branch 0.12. `tree-sitter-cli` is 0.20.8 or missing where `main` needs 0.26, and starship, yazi, glow and lazygit aren't packaged at all. devpod and Fedora/Arch got none of these tools, because the apt script skips devpod and only Debian has a manifest. The mise registry now carries every one of them through aqua backends, i.e. the projects' own prebuilt release binaries with checksums.

**Decision:** on Linux the CLI tool Applications delta, starship, neovim, fzf, zoxide, yazi, glow, bat, lazygit, tree-sitter-cli, ripgrep and fd come from the global mise config: `home/dot_config/mise/config.toml.tmpl` maps each app to one aqua tool at `latest`, just as the other manifests map apps to package IDs. apt keeps system packages (tmux, unzip, cmake, build-essential) and the GUI apps. macOS and Windows stay on Homebrew and winget, whose versions are current. This partly supersedes ADR 0008's "mise stays for language runtimes", for Linux only.

**Consequences:** a Debian/Ubuntu machine, a devpod, and any other Linux distro get current tool versions without sudo; the binaries live under `~/.local/share/mise` and reach the PATH through `mise activate` in `.bashrc`/`.zshrc` and the shims in `.zprofile`. chezmoi scripts that call those tools, like the yazi plugin install, put the mise shims on their PATH themselves. `mise install` resolves `latest` through the GitHub API, which allows 60 unauthenticated requests per hour; a machine or CI job that installs often needs a `GITHUB_TOKEN` in its environment. Updates come with `mise upgrade`, not `apt upgrade`. A machine provisioned earlier keeps its apt copies of the moved tools until they are removed by hand; mise's come first on the PATH.
